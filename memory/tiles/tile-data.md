## Data Maintenance Notes

- Add new tiles to the Tile Index as soon as Awakening creates or targets them.
- Add a new file under `records/` for each new tile's detail record; keep only the summary row here in the Tile Index.
- Add keyword IDs from `keyword-list.md` rather than repeating full interpretations in every tile row. Not every Cartography result becomes a keyword — see the recurrence rule at the top of `keyword-list.md`: a result only earns an ID if a second tile independently draws it, or Chronicle's Seed mechanism creates it as a return condition. A one-off result stays a plain tag.
- Keep unresolved items short and concrete.
- Move phase narrative into `../narrative/sessions/` (one file per session; see `../narrative/suolenkainen-map.md` for the index); keep durable tile facts here and in `records/`.
